# Homebrew Tap for Storage Unleashed 🍺

Official Homebrew tap for [Storage Unleashed](https://www.storageunleashed.com) — Fast, visual, and privacy-first storage analyzer for macOS.

## Installation

```bash
brew install rajnishcoder/tap/storageunleashed
```

Or via direct tap:

```bash
brew tap rajnishcoder/tap
brew install --cask storageunleashed
```

## Update

```bash
brew upgrade storageunleashed
```

## Uninstall

```bash
brew uninstall --zap storageunleashed
```
